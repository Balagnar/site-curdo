# 🌿 Casa de Umbanda - Centro Umbandista Rei de Oxóssi

Um site moderno e responsivo desenvolvido para o **Centro Umbandista Rei de Oxóssi**, focado em apresentar os horários das giras, atendimentos espirituais, ações sociais e informações da casa para a comunidade.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica do site.
- **Tailwind CSS (via CDN)**: Estilização moderna, ágil e responsiva através de classes utilitárias.

---

## 🎨 Funcionalidades do Projeto

- [x] **Cabeçalho (Header)** com menu de navegação e destaque visual no link ativo.
- [x] **Seção Principal (Hero Section)** com apresentação do santuário e botões de chamada para ação.
- [x] **Cards Informativos** organizados em grid responsivo (Nossas Giras, Atendimento Espiritual e Ações Sociais).
- [x] **Rodapé (Footer)** com direitos autorais e layout limpo.

---

## 📁 Como rodar o projeto localmente

1. Clone este repositório:
   ```bash
   git clone [https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git](https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git)
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd SEU_REPOSITORIO
   ```
3. Abra o arquivo `index.html` em qualquer navegador ou utilize a extensão **Live Server** no VS Code.
